# 深海ダイブ（deepsea-dive）

実際の海底地形データをもとに、世界の深い海を3Dで潜航・探査できるWebサイトです。three.js で動作し、ブラウザだけで遊べます。

## 潜れる海

| 海 | ページ | 潜航地点 |
|---|---|---|
| マリアナ海溝 | `seas/mariana/` | チャレンジャー海淵 |

## 遊び方

- **俯瞰モード**: ドラッグで回転、ホイールで拡大、右ドラッグで移動。
- **潜航モード**: 「潜航開始」を押すと、上空から海面へ降り、ゆっくり海中に入ります。
  - 移動: `W` `A` `S` `D`（毎秒10m）／上昇 `E`・`Space`／下降 `Q`・`C`／ライト `L`／撮影 `P`／ドラッグで見回す
  - 深さを大きく変えるときは、マウスホイールか右の深度ルーラー（クリックでその深さへ）を使います。
  - 上の「ダイブマップ」タブ（M キー）で地図に切り替え、好きな地点を選んで「ここに潜る」で移動します。地図はドラッグで動かし、ホイールや＋－で拡大できます。陸地を選んだときは、いちばん近い海から潜ります。浅瀬や海岸の近くにも行けます。
- **ソナー**: 海中では10秒ごとに音波を発信します。波面は海水中の音速（約1,500 m/秒）で広がり、届いた地形が数秒間浮かび上がります。
- **生き物と図鑑**: 生き物は海の中の決まった場所に住んでいて、同じ場所に戻れば同じ個体に会えます。深海では潜水艇のライトに照らされたときだけ見えます。海底の近くまで降りると、海底の生き物を間近で観察できます。初めて出会った生き物は「図鑑」に登録されます。形と動きはプログラムで作っていて、3Dモデルのファイルは使っていません。公開前の生き物（`config.js` で `status: 'preview'`）は通常は表示されません。
- **生き物の動き**: マッコウクジラは時刻に合わせて決まった海域を回遊し、深く潜っては浮上します（近くにいると、反響定位のカチカチという音が来る方向から聞こえます）。ハダカイワシの群れは近づくと散り、カイコウオオソコエビは潜水艇が止まっていると集まってきます。ナマコは海底に這い跡を残します。
- **ライトと撮影**: 「ライト」（`L`）で潜水艇のライトを消すと深海は真っ暗になり、自分で光る生き物や、動いたときに光るプランクトンが見えます。「撮影」（`P`）で画面の中央に写った生き物の写真が、図鑑に貼られます。
- **見どころ**: 海底のどこかに、クジラの骨（鯨骨）・沈んだ木・実在の熱水噴出孔（スネイルサイト）・観測装置・海の底のプラスチック袋があります。場所の手がかりは図鑑の「実績」に書いてあります。
- **本物らしさ**: チャレンジャー海淵・シレナ海淵・熱水噴出孔のまわりは、船の音響測深にもとづく細かい地形です。チャレンジャー海淵の底が3つのくぼみに分かれている様子や、海溝の外側の斜面に並ぶ階段状の断層が分かります。グアム島のまわりは細かい地形（約120m 格子、陸地の高さも含む）で、島の海岸線・サンゴ礁の礁原・アプラ港・ココス礁湖が分かります。浅い海は海底の白い砂やサンゴが透けて青緑に見え、礁の縁や浜では波が砕けます。陸地は高さを強調せず、熱帯の森・石灰岩の崖・砂浜で描いています。海面より上から見る浅い海は、海底（白い砂・サンゴ・光の網目）が波でゆがんで透けて見え、水深40mより浅い海底には砂紋とサンゴの群体（ハマサンゴ・ノウサンゴ・テーブル状と枝状のミドリイシ。表面のポリプの穴や溝も描いています）があり、岩とサンゴが積み重なった根や、礁の斜面に並ぶ尾根と溝（縁脚・縁溝）の起伏があります。サンゴ礁には、グアムの礁にすむ魚の群れ（デバスズメダイ・キンギョハナダイ・ナンヨウハギ・ツノダシ・クマノミなど 11 種と、渦を巻くギンガメアジの銀色の群れ）と、イソギンチャク・シャコガイ・ウミウチワ・海草などがいて、ブダイはサンゴをかじり、ホンソメワケベラの掃除場には魚が掃除をしてもらいに来ます。ときどきネムリブカ・マダラトビエイ・ナポレオンフィッシュが通り過ぎます。ダイブマップには、グアムの実在のダイブポイント（位置はおおよそ）があり、それぞれの名物の生き物に出会えます: ピナクル（海底からそびえる岩の塔に、渦を巻くバラクーダの群れ・イソマグロ・ギンガメアジ）、マンタポイント（旋回するナンヨウマンタと、マンタが通う掃除場）、ブルーアステール（ウミガメ・タイマイ・ツマグロ・マルコバンアジ）、アプラ湾の東海丸（横倒しに沈んだ貨物船と、その暗がりのドウクツハタンポ。湾の中でもこのまわりは澄んでいます）。サンゴの庭（フィンガーリーフの枝サンゴの林・グアム東岸のテーブルサンゴ・リティディアン沖のイソギンチャク畑）もあります。外洋の海面近くでは、ハシナガイルカの群れが泳いでジャンプし（海面にいるときは、海面から跳び出す姿が見えます）、トビウオが海面から飛び出して滑空し、キハダの群れが通り過ぎ、ところどころに浮かぶ流木の下にはシイラが集まります（いずれも公開前の表示）。水深約20mまでの浅瀬は、本物らしさより美しさを優先し、本物より赤や黄の光を多く残して水も澄ませ、サンゴを鮮やかな色にしています（20〜45mでなめらかに本物どおりに戻ります）。浅瀬では光の網目が明るく縁に少し虹色がにじみ、光の筋の中を光の粒が漂い、見上げると波で砕けた太陽がきらめきます。海面の上からは、水深ごとに水色・青緑・濃い青の帯に分かれたラグーンが見えます。画質「中」以上では光の筋が差し込み、画質「高」では、日の光でサンゴや魚の影が海底に落ち、光の筋も影で途切れます。島の木は葉の模様と切り抜きで描き、山や崖の影が地面と木に落ちます。砂浜では波が駆け上がっては引き、濡れた砂と泡の線ができます。海面の波は、この海域で吹く貿易風（東北東の風）の風浪スペクトルから作っていて、西南西へ進みます。西北西の低い太陽が、海面にきらめきの道を作ります（さざ波の傾きの分布から計算）。空には平らな底ともこもこした頭の積雲が浮かび、高い波の山には白波が立ちます。水は赤い光から先に吸うので、深くなるほど、また遠くの物ほど青く見えます。浅い所では、潜水艇が波の下の水と一緒にゆっくり揺れ、海底や生き物の体に光の網目（コースティクス）が揺れます。見通しは数十 m で、見上げると上ほど明るい水の色が約1,000 m まで残ります。潜水艇のライトは窓の左右に付いていて、光の筋がうっすら見えます。ソナーの音は、その深さの音速（水深1,000 m 付近で約1,485 m/秒、海溝の底で約1,655 m/秒）で広がり、海底からのこだまは往復の時間だけ遅れて返ります。ライトの光の中にはマリンスノーが浮かび、ゆっくり沈みながら、潮の周期でゆっくり向きを変える底層流に流されていきます。海底すれすれを進んだり着底したりすると泥が舞い上がって、しばらく視界が悪くなります（画面下に海底までの高さを表示）。マリアナスネイルフィッシュは近くのヨコエビを追いかけて食べます。海底の近くでは、急な斜面は岩場、平らな所は泥になります。魚がすめる限界（約8,200 m）より深くには、ほとんど魚はいません（これまでに撮影された最も深い魚は8,336 m）。超深海では、海溝の軸に近い谷底ほど生き物が多くなります。遠くの地震の地鳴りや、海面を通る船の音も聞こえます。
- **実績**: 名前のついた場所（チャレンジャー海淵の底、シレナ海淵の底、グアム島の海）や見どころに着いたとき、節目の深さを越えたときなどに実績が解除されます。図鑑・写真・実績の記録は、このブラウザに保存されます。
- **音**: ページを開くと音を再生するか確認します。BGM（深さに合わせて変わる環境音楽）と効果音（波・泡・ソナー・モーターなど）は、すべて Web Audio でその場で合成しています（音声ファイルなし）。画面下の「BGM」「効果音」ボタンと音量スライダーで切り替えられます。

## フォルダ構成

```
index.html            トップページ（潜れる海の一覧）
engine/               すべての海で共通の仕組み
  world.js            地形メッシュ・水中の見え方・ソナーの表示
  sea.js              空・海面（ゲルストナー波）・光の筋・泡
  audio.js            BGM・環境音・効果音（Web Audio で合成）
  species.js          生き物の形と動き（プログラムで生成）
  creatures.js        生き物の住む場所と描画（カメラの周りをメートル単位の近景として重ねて描く。近くの海底も）
  zukan.js            生き物図鑑と実績
  ui.js               計器・深度ルーラー・ボタン・ダイブマップ・画質（動きが重いときは描画の細かさを自動で下げる）
  post.js             仕上げ（HDR・光のにじみ・明るさの変換）
  coast.js            島の近くの細かい陸地・衛星写真・木
  treasure.js         隠し要素
  nav.js              移動・入水演出・ソナー発信・描画ループ
  engine.css          共通スタイル
tools/
  record_preview.py   プレビュー動画の録画スクリプト
  update_versions.py  JS・CSS の読み込みに版番号を付ける
  make_detail.py      海の一部を細かい地形にするデータ（detail.js）を作る
seas/<海のID>/
  index.html          その海のページ（出典の記載を含む）
  bathy.js            海底地形データ（下記の形式）
  detail.js           一部だけの細かい地形データ（なくてもよい）
  config.js           その海の設定（潜航地点・地名・深さの区分・生き物など）
```

## 海の追加方法

1. `seas/mariana/` をコピーして `seas/<新しいID>/` を作る。
2. `bathy.js` を新しい海域の地形データに置き換える。形式は次のとおり:
   - `window.BATHY = { nlat, nlon, lat0（北端）, lat1（南端）, lon0（西端）, lon1（東端）, step（格子間隔・度） }`
   - `window.BATHY.b64` … 標高（m、整数）を北→南・西→東の順に並べた Int16 リトルエンディアン配列の Base64
3. `config.js` の `id`・`name`・`origin`（潜航地点を探す範囲）・`features`（地名）・`zones`・`life`・`creatures`（3Dで泳ぐ生き物）などを書き換える。
4. `index.html` のタイトルと出典欄を書き換え、トップページの一覧にカードを追加する。

地形データは NOAA CoastWatch ERDDAP から CSV で取得できます（例: データセット `ETOPO_2022_v1_15s`）。

## 更新するときの手順

ページが読み込む JS・CSS には、ファイルの中身から計算した版番号（`?v=xxxxxxxx`）を付けています。変更したファイルだけ番号が変わるので、訪問者のブラウザに古いファイルが残りません。**更新をプッシュする前に必ず実行してください。**

```
python tools/update_versions.py
```

HTML 自体は GitHub Pages の設定で最大10分ほどブラウザに保存されるため、反映に少し時間がかかることがあります。

## プレビュー動画の作り方

`tools/record_preview.py` で、SNS用のプレビュー動画（1280×720・30fps の MP4）を作れます。ページの時計を1コマずつ進めて撮影するので、PCの速さに関係なくなめらかな動画になります。

```
pip install selenium pillow imageio-ffmpeg
python tools/serve.py               # リポジトリのルートで起動しておく（http://localhost:8740/。ブラウザに古いページを使い回させない）
python tools/record_preview.py      # promo/preview.mp4 に出力（promo/ は Git 管理外）
```

Google Chrome が必要です。

## データ出典と利用条件

- **海底地形**: NOAA National Centers for Environmental Information. 2022: ETOPO 2022 15 Arc-Second Global Relief Model. NOAA National Centers for Environmental Information. https://doi.org/10.25921/fd45-gt74 （2026-09-28 取得）
  - NOAA CoastWatch ERDDAP のデータセット `ETOPO_2022_v1_15s` から、1点おき（30秒角 ≈ 0.9 km 間隔）に取得。
  - 利用条件: **CC0 1.0**（パブリックドメイン）。**航行用には使用できません。**
- **細かい地形（チャレンジャー海淵・シレナ海淵・熱水噴出孔の周辺）**: Ryan, W. B. F. et al. (2009), Global Multi-Resolution Topography synthesis, Geochem. Geophys. Geosyst., 10, Q03014, https://doi.org/10.1029/2008GC002332 （[GMRT](https://www.gmrt.org/)、2026-10-02 取得）
  - GMRT GridServer から高解像度格子（船の音響測深データにもとづく）を取得し、チャレンジャー海淵（北緯10.95–11.6°・東経141.9–143.0°）とシレナ海淵（北緯11.85–12.25°・東経144.25–144.9°）は約240 m 間隔、熱水噴出孔（北緯12.85–13.05°・東経143.5–143.75°）とグアム島の周辺（北緯13.18–13.72°・東経144.57–145.03°、陸地を含む）は約120 m 間隔に平均。`tools/make_detail.py` で作成。グアム島の周辺の格子には、アプラ港の中などに、まわりが水深数十 m なのに 1,000〜2,600 m になっている誤った値があるため、外の深い海につながっていない深いくぼみは、読み込むときに、まわりの海の深さからなめらかに埋めています（`engine/world.js`）。
- **グアム島の衛星写真（`seas/mariana/guam_sat_*.webp`）**: Sentinel-2 cloudless - https://s2maps.eu by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2016 & 2017)、CC BY 4.0。`tools/make_guam.py` で作成。
- **グアム島の細かい陸地の高さ（`seas/mariana/guam_dem.webp`、約20 m）**: Mapzen Terrain Tiles（AWS Open Data）。United States 3DEP (formerly NED) and global GMTED2010 and SRTM terrain data courtesy of the U.S. Geological Survey. 海岸近くの海が陸になっている所は、GMRT と衛星写真の水の色で海に直しています。
  - ダイブマップの背景画像（`seas/mariana/map.webp`）は、GMRT の約120 m 格子から `tools/make_map.py` で作成（約160 m / 画素）。グアム島以外で海面より高く出ている浅い礁（サンタローサ礁など）は、データの誤差として水深6 m の浅瀬にしています（`config.js` の `islands`）。
  - 利用条件: **CC BY 4.0**（出典の表示が必要）。
- **チャレンジャー海淵の実測深度（約10,935 m）**: Greenaway ほか (2021), Deep-Sea Research Part I。
- **熱水噴出孔（スネイルサイト）の位置と深さ**: マリアナトラフ南部の背弧拡大軸、北緯12°57.2′・東経143°37.1′、水深約2,860 m（JAMSTEC などの調査報告）。
- **海底のプラスチック袋**: 1998年に水深10,898 m で撮影された記録（Chiba ほか 2018, Marine Policy／JAMSTEC 深海デブリデータベース）。ゲーム内の位置は表現用です。
- **深海の音**: 2015年にチャレンジャー海淵の底で録音された地震・ヒゲクジラの声・船の音（NOAA ほか）をもとに、音はその場で合成しています（録音そのものは使っていません）。
- 水温・太陽光・生き物の解説は一般的な知見にもとづく概算です。海面の波は Pierson–Moskowitz の風浪スペクトル（風速 8 m/秒）から作ったもので、観測データではありません。雲・光の筋は表現用に作ったものです。
